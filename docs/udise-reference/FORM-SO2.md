# Form SO2 / UDISE+

## Purpose

Format to add a student **only for Classes 2–12** when the student's profile is not yet created / is missing in UDISE+ SDMS. It is for school records and submission to Block/District Education Officer or equivalent authority.

## Submitted-by / school fields

- Current Academic Year
- UDISE Code
- School Name
- Head of School contact details
- State
- District
- Block

## Student fields

- Name
- Gender
- Date of Birth
- Is CWSN?
- Class
- Section
- Admission Date
- Father's Name
- Mother's Name
- Mobile Number
- Guardian's Name (if applicable)
- Aadhaar Number
- Name as per Aadhaar

## Reason for non-creation of student profile

The form lists these reason categories:

1. Student rejoining after dropping out
2. Student admitted from unrecognized/open school
3. Profile not created by current school in previous year
4. Profile not created by previous school in previous year
5. Student from other country

## Supporting documents

- Copy of School Register / Admission Register attested by HoS — mandatory for verification of enrolment, student name, gender and DOB as per school record
- Copy of Birth Certificate attested by HoS — for DOB
- Copy of Transfer Certificate / School Leaving Certificate, if applicable

## Undertaking / verification

The undertaking confirms that the information is correct and verified, supporting documents have been checked, and the student has been searched in UDISE+ Global Search with no existing profile found.

Sign-off blocks are provided for:

- Head of School
- Block Education Officer or equivalent
- District Education Officer or equivalent

Each includes agreement to the undertaking plus signature, name, designation, date and seal.

## Automation implication

Before preparing SO2, the dashboard should first search the student across the available school datasets and, where relevant, UDISE Global Search / Dropbox workflows. Missing or conflicting fields must be surfaced for manual review rather than silently filled.
